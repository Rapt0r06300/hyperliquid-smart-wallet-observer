# GitHub License Audit

## Phase 0 result
No external repository code was copied in Phase 0.

## Policy
Before any direct copy:

1. Record repo URL, commit hash, license, and file path.
2. Confirm license compatibility with this project.
3. Prefer behavior porting over direct copy.
4. Add tests proving no real order, no private key, no signature, no `/exchange`.
5. Add attribution where required.

## Current status
Most external repos remain `PORT_BEHAVIOR`, `INSPIRE_ONLY`, or `RESEARCH_ONLY` until license review is complete.
