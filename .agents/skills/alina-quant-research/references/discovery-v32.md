# Discovery V3.2 — quota-first semantic control plane

V3.2 wraps the V3.1 scientific controller; it does not replace economic gates. Use this reference only during Discovery, Rediscovery or champion-challenger work.

## Context first

Run `python tools/codex_research_context.py --auto`. Do not reconstruct state by reading full Git history, the sealed 775 optimization list, all docs or raw trial logs. The local context pack should answer what family is underworked, what failed/succeeded, what is vetoed, how much search pressure accumulated, and what actions are admissible.

## Semantic expansion on CPU

Use `codex_semantic_discovery.py` to generate a broad **semantic** Cartesian pool over event × context × data surface × temporal operator × regime × target × execution. CPU may enumerate thousands of candidates without spending model turns.

The local engine should:
- reject declared invalid combinations;
- exact-dedupe and near-dedupe candidates against evaluated ledger semantics;
- apply process-memory **veto** only after repeated high-confidence failure for sufficiently equivalent mechanism+context;
- allow **retest** when documented new data/surface, materially different causality or fresh contradictory evidence satisfies the condition;
- use positive memory only as a bounded soft boost;
- rank novelty, under-covered surfaces, data feasibility, falsification efficiency and executable-headroom hints;
- return a small archetype-diverse shortlist.

The ranking is research scheduling only. It cannot certify PnL.

## Model realization

The LLM spends reasoning only on the shortlist: refine causal story, check identifiability, define falsification, choose cheap tournament tests, then dispatch local computation. Avoid a model turn between trials that can be predefined.

Default realized Discovery set: 12 hypotheses, minimum 8, >=5 archetypes. Cosmetic threshold/window/seed changes are `PARAMETER_ONLY`.

## Memory asymmetry

Negative high-confidence repeated evidence may stop rediscovery of the same failed region. Positive evidence never grants a pass: it only increases priority slightly. Any OOS/forward evidence used for adaptation loses held-out status.

## Economic invariants

Full fees, spread, slippage, latency, capacity, fill/liquidatability, closed positions, provenance, no-lookahead, frozen parameters, OOS and strict post-freeze forward remain mandatory. Final target remains >= +4 USD NET/day separately for each canonical family on the exact certified HEAD.
